# SDDM login screen

This component is the graphical login frontend shown before a Plasma session starts. It uses SDDM's own user, session, and authentication APIs. It does not replace SDDM or modify PAM.

From the repository root, run `bash install.sh --sddm` to build and stage it under `/usr/share/sddm/themes/matrix-greeter`. The runtime files are installed root-owned; an existing theme directory is deliberately not overwritten. Preview before activation:

```bash
sddm-greeter-qt6 --test-mode --theme "$PWD/sddm"
```

Test mode does not authenticate. Check the user and session selectors, keyboard controls, password field, and power confirmation. Only after the preview works, select **Matrix Greeter** in Plasma System Settings → Login Screen (SDDM). Do not restart SDDM from an active graphical session; doing so ends that session.

To recover from a broken greeter, use `Ctrl+Alt+F3` to enter a TTY and inspect the effective theme settings in `/etc/sddm.conf.d/`. Restore a known-good installed theme through System Settings when possible. If a TTY change is necessary, make a specific SDDM theme override after checking which configuration file takes precedence. Rebooting or restarting SDDM can end unsaved graphical work.

The `.qsb` shader is generated by `build.sh` and excluded from Git. `theme.conf` contains the default rain quality, density, brightness, and motion values; `theme.conf.user` may override them after installation. `login-preview.png` is a screenshot of the running SDDM theme. `tools/make_assets.py` is optional and requires Pillow and NumPy; the installed theme does not. `tests/check.py` performs structural checks, not a real login test.
